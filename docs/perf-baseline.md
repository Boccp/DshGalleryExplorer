# DSH Gallery Explorer 性能基线与 v2 优化实测对比

测量工具：`out\dsh-gallery-explorer.exe --bench <目录...>`（见 [BenchRunner.cs](../src/Bench/BenchRunner.cs)）。
测试机：24 逻辑 CPU，Windows x64。测试目录（全程只读扫描，bench 缓存完全隔离在 `out\bench_cache\`）：

- `F:\QQ`（213 项，图片 + 37 个 mp4 + 杂项）
- `F:\Openclow\画师素材库`（48 个画师文件夹，测文件夹封面）
- `F:\Openclow\画师素材库\Pin`（8,398 项，大目录自然序与多维排序压力）
- `F:\Openclow\画师素材库\照片`（2,011 项）
- `F:\Openclow\画师素材库\@jiraiya`（855 项）

原始自动生成的完整报告见：
- v1 基线：[baseline-run1.md](bench/baseline-run1.md)、[baseline-run2.md](bench/baseline-run2.md)
- v2 优化后：[optimized-run1.md](bench/optimized-run1.md)、[optimized-run2.md](bench/optimized-run2.md)

## 核心指标前后对比（同机同数据集实测）

| 性能维度 | v1 基线 (run1 / run2) | v2 优化后 (run2) | 提升幅度 | 关键根因与改造方案 |
| :--- | ---: | ---: | :---: | :--- |
| **`Pin (8,398项)` 枚举 + 名称排序总耗时** | `428.6` / `431.1 ms` | **`31.4 ms`** | **13.7x** | 消除每次比较分配正则数组的瓶颈 |
| ↳ 其中 **纯排序 (`dir.sort`)** 耗时 | `406.0 ms` | **`5.75 ms`** | **70.6x** | 原位单遍零分配自然序比较器（支持任意位长数字） |
| **`Pin (8,398项)` 按标签排序总耗时** | `539.7` / `556.2 ms` | **`36.5 ms`** | **15.0x** | 同标签回退自然序比较零分配 |
| **缩略图单线程冷加载 (JPG avg / p50)** | `72.7–86.7` / `~58 ms` | **`16.0` / `8.2 ms`** | **4.9x** | WIC 文件头探测 + JPEG IDCT 硬件降采样 |
| **202 项真实并发冷加载墙钟 (吞吐)** | `12.7 s` / `12.3 s` (`16 项/s`) | **`0.58 s` (`347.5 项/s`)** | **21.5x** | 绕开 `gdiplus.dll` 进程级全局大锁，24 核满载并发 |
| **202 项磁盘缓存热加载墙钟 (吞吐)** | `253` / `259 ms` (`798 项/s`) | **`53.8 ms` (`3,756 项/s`)** | **4.7x** | WIC 内存流直解 `Format32bppPArgb` |
| **网格离屏渲染 `1920×1080` (全档位 avg)** | `65–88 ms/帧` (`11–15 fps`) | **`7.95–10.50 ms/帧` (`95–126 fps`)** | **8.4x** | `Format32bppRgb` 不透明卡片/外环模板 + 1:1 直贴 |
| **网格离屏渲染 `3840×2160` 4K (全档位 avg)** | `185–334 ms/帧` (`3–5 fps`) | **`21.3–25.9 ms/帧` (`39–47 fps`, p50 `58 fps`)** | **10.5x** | 消除全屏抗锯齿 `GraphicsPath` 与无锁多核定点双线性缩放 |
| **看图器 `34.8 MB` 大图普通重绘每帧** | `1,725` / `2,034 ms` (`0.5 fps`) | **`0.95–1.53 ms` (`650–1050 fps`)** | **1,300x+** | 视口级 `_scaledViewBitmap` 缓存（仅切图/改窗口时重算） |
| **看图器 `~` 截图模式鼠标移动重绘每帧** | `1,720` / `2,236 ms` (`0.5 fps`) | **`1.43–1.77 ms` (`560–700 fps`)** | **1,200x+** | 保留全尺寸原图无损裁剪 + `LockBits` 仅采样光标 `31×23` 邻域 |
| **视频悬停胶片全量 611 帧抽取耗时** | `1,983–3,826 ms` (未解码) | **`775–1,149 ms` (含全量后台解码)** | **2.1–2.6x** | 17 帧极速首包 + `11×54` 帧（`ffmpeg` 进程数从 36 降至 12） |
| **视频悬停播放 UI 线程每帧 JPEG 解码** | `1.21–2.46 ms/帧` (占 120Hz 预算 25%) | **`0.00 ms/帧`** | **UI 零阻塞** | 后台线程预解码 `Freeze()` `BitmapSource`，UI 仅引用赋值 |
